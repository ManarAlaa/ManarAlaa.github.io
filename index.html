About

I build backend systems — APIs, real-time services, and the business logic that sits behind them. Most of my production work has been on service and operations platforms: designing data models, structuring authentication and authorization, integrating third-party and real-time data sources, and keeping systems reliable as requirements change.

I'm drawn to problems where data has to move correctly and on time between systems — a WebSocket connection that can't drop a bid, a cron job that has to run exactly once, an API that an external partner is depending on. Getting that right, over building something that just looks finished, is what I care about.

Alongside production work, I'm developing depth in NestJS, system design, automated testing, and containerized deployment — the layer above individual services, where backend architecture decisions actually get made.
